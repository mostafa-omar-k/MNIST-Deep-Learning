# MNIST Neural Network From Scratch

A Python implementation of a simple **Neural Network from scratch** for classifying handwritten digits from the MNIST dataset.

## Features

* Load and preprocess the MNIST dataset.
* Standardize input features.
* Split data into training and testing sets.
* Apply One-Hot Encoding to labels.
* Implement a Neural Network from scratch using NumPy.
* Implement Forward Propagation.
* Implement Backward Propagation.
* Train and evaluate different network architectures.

## Models Tested

| Model   | Architecture | Accuracy |
| ------- | ------------ | -------: |
| Model 1 | 6 → 1        |   14.61% |
| Model 2 | 6 → 4 → 1    |   10.34% |
| Model 3 | 4 → 6 → 1    |    9.55% |
